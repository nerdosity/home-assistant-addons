# nerdosity / home-assistant-addons

Repository di distribuzione degli add-on Home Assistant mantenuti da [nerdosity](https://github.com/nerdosity).

## Add-on disponibili

- **[Connectlife API proxy & MQTT Add-on](connectlife-api-connector/)** — integra i condizionatori Hisense ConnectLife in Home Assistant via MQTT discovery.

## Installazione

In Home Assistant:

1. **Settings → Add-ons → Add-on Store**
2. Menù in alto a destra (tre puntini) → **Repositories**
3. Aggiungi: `https://github.com/nerdosity/home-assistant-addons/`
4. Gli add-on di questo repository compariranno nello store dopo qualche secondo (eventualmente "Reload" dal menù).
